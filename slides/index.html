Git vs GitHub

Two different things. Everyone mixes them up.

Git is local. GitHub is the broadcast.

commitone saved snapshot
pushsend it up to GitHub

Get Set Up

Conflicts

          
Not a disaster. Git is asking you a question.

        


        

          Which line do you want?
          

            
            
            
          

        


        

          Make one on purpose
          
    
            
  1. Terminal Type git switch main, Enter.
    2. 
            
  2. GitHub In your fork, open conflict.txt, click the pencil, change (change this line) to any language, Commit changes
    3. 
            
  3. VS Code Open conflict.txt. Change that same line to a different language. Save.
    4. 
            
  4. Terminal Type git add . then git commit -m "mine" then git pull You see: CONFLICT. Good, that's the point.
    5. 
            
  5. VS Code In conflict.txt, keep the line you want. Delete the <<<, === and >>> lines. Save.
    6. 
            
  6. Terminal Type git add . then git commit -m "fixed" then git push
    7. 
          

          
</>Way out: git merge --abort
